# Генератор мемов

## Описание

Небольшое настольное приложение на Python и PyQt6 для создания мемов из текстовых заготовок и изображений. Выберите шаблон в таблице, посмотрите предпросмотр или добавьте собственные заготовки с картинкой. Шаблоны и ежедневная статистика генераций хранятся в SQLite-базе `memes.db`; при первом запуске данные из прежнего `memes.json` импортируются автоматически. График активности за последние семь дней сохраняется между запусками приложения.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows активируйте окружение командой `.venv\Scripts\activate`.

## Тесты

Установите зависимости из `requirements.txt`, затем запустите тесты:

```bash
QT_QPA_PLATFORM=offscreen python -m pytest
```

## Краткая справка

- Выберите заготовку в таблице, чтобы увидеть подписи в предпросмотре.
- Заполните название, категорию и хотя бы одну подпись. Кнопкой «Выбрать…» можно добавить изображение; «Убрать» снимает его выбор.
- Нажмите «Добавить заготовку», чтобы сохранить шаблон вместе с путём к выбранной картинке.
- Нажмите «Создать мем», чтобы записать действие в журнал и обновить график активности.
- Заготовки сохраняются в SQLite-базе `memes.db` рядом с приложением. Старый `memes.json` импортируется при первом запуске, если база ещё пуста.
- В меню «Файл» доступны добавление, создание и выход; `Ctrl+Return` создаёт мем, `Ctrl+Q` закрывает приложение.
