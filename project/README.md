# Генератор мемов

## Описание

Небольшое настольное приложение на Python и PyQt6 для создания мемов из текстовых заготовок и изображений. Выберите шаблон в таблице, посмотрите предпросмотр или добавьте собственные заготовки с картинкой. Приложение сохраняет их в `memes.json`, показывает количество созданных мемов за последние семь дней и ведёт журнал действий.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows активируйте окружение командой `.venv\Scripts\activate`.

## Краткая справка

- Выберите заготовку в таблице, чтобы увидеть подписи в предпросмотре.
- Заполните название, категорию и хотя бы одну подпись. Кнопкой «Выбрать…» можно добавить изображение; «Убрать» снимает его выбор.
- Нажмите «Добавить заготовку», чтобы сохранить шаблон вместе с путём к выбранной картинке.
- Нажмите «Создать мем», чтобы записать действие в журнал и обновить график активности.
- Заготовки сохраняются в `memes.json` рядом с приложением.
- В меню «Файл» доступны добавление, создание и выход; `Ctrl+Return` создаёт мем, `Ctrl+Q` закрывает приложение.
