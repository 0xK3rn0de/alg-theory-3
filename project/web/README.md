# Генератор мемов — Web

Веб-версия приложения на Django. Шаблоны мемов, изображения и ежедневная статистика хранятся в PostgreSQL. Веб-интерфейс позволяет выбирать заготовки, загружать изображения и создавать мемы с сохранением активности.

## Запуск в Docker

Из этой папки выполните:

```bash
docker compose up --build
```

После запуска откройте <http://localhost:8000>. Django применит миграции автоматически; PostgreSQL и пользовательские изображения сохраняются в Docker volumes. Для остановки нажмите `Ctrl+C`, затем `docker compose down`. Данные БД остаются в volume. Чтобы удалить их тоже: `docker compose down -v`.

Для своих настроек скопируйте `.env.example` в `.env` и измените секретный ключ и пароль PostgreSQL. Значения по умолчанию предназначены только для локальной разработки.

## Тесты

Тестовый набор использует SQLite и не требует запущенного Docker:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest
```

В Windows активируйте окружение командой `.venv\Scripts\activate`.

## Основные сценарии

- Выберите заготовку в библиотеке, чтобы показать её подписи и изображение.
- Заполните форму и добавьте шаблон, загрузив PNG, JPG или WebP размером до 5 МБ.
- Нажмите «Создать мем»: ежедневный счётчик генераций сохранится в PostgreSQL.
- Административная панель доступна по адресу `/admin/` после создания суперпользователя командой `docker compose exec web python manage.py createsuperuser`.
